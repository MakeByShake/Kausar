# Дизайн-бриф Kausar

**Настроение:** яркий, сочный, добрый казуальный стиль (как Hay Day, Gardenscapes, Candy Crush), но спокойный и уважительный: это сад, а не аркада. Свои рисунки, никаких копий.

**Палитра:** бирюза `#1FB5A6` (основная), золото `#FFC94D → #FF9F1C` (кнопки), небо `#7FD8FF`, трава `#4CC85A`, вода `#4FC3F7`, акценты розовый `#FF6FB1`, сиреневый `#B57BFF`.

**Форма:** большие скруглённые кнопки с белой обводкой 3 px и толстой нижней тенью, «нажимаются» вниз. Плашки-капсулы. Шрифт жирный, с мягкой тенью.

**Что нужно нарисовать (этап 2), каждый предмет в 3 состояниях: росток → половина → готово:**
- трава/лужайка, 4 вида цветов, куст с ягодами, дерево с плодами, финиковая пальма
- ручей, мостик, фонтан, фонарь
- беседка/шатёр, дворец с куполом (без людей и животных)
- фоны: день, закат, ночь (звёзды) для разных садов
- иконка приложения: капля + росток/пальма
- анимации: «выпрыгивание» нового предмета, падающие капли, блики на воде, салют при завершении сада

**Инструменты:** генерация ИИ (Midjourney/Ideogram/Recraft, стиль «3D clay casual game asset, soft lighting, isolated on transparent») → чистка в Figma → экспорт PNG @2x/@3x. Для анимаций — Rive (бесплатный, есть Flutter-пакет) или Lottie.

**Открытые источники для вдохновения и кода:**
- Flame (игровой движок Flutter): https://github.com/flame-engine/flame
- Rive Flutter: https://github.com/rive-app/rive-flutter
- flutter_animate: https://github.com/gskinner/flutter_animate
- Kenney (бесплатные ассеты CC0, много растений и UI): https://kenney.nl/assets
- Дизайн-референсы: Forest, Finch, Duolingo (стрики, мотивация), Jannaty (конкурент).
