# Kausar (Кәусар) — игра-приложение с зикрами

Читай этот файл первым. Здесь всё, что нужно знать о проекте.

## Что это
Мобильная игра (iOS + Android, Flutter) для мусульман Казахстана. Человек делает зикр
(тапает по экрану, как на тасбихе), за это получает «капли Каусара» 💧 и растит ими
свой сад: трава → цветы → деревья → пальма → ручей → беседка. Когда сад полностью
вырос, открывается следующий, ещё красивее (карта садов, как карта уровней).
Опора на хадисы: «Кто скажет "Субханаллахи ва бихамдихи", тому посадят пальму в раю»
(ат-Тирмизи); тасбих/тахмид/тахлиль/такбир — «саженцы рая».

Кто делает: Qazaq (Шералхан Мухаммад, студент, GitHub BayBolVS) + автор идеи. Код пишет
Claude, Qazaq проверяет и решает. Язык общения — русский, коротко, без воды.

## Жёсткие правила продукта (не менять без согласия Qazaq)
1. **Никакого соревнования по зикрам.** Нет рейтингов, лайков, публичного счёта зикров.
   Причина: рия (показуха). Игра — только для себя.
2. **Полностью бесплатно.** Никаких покупок, рекламы, подписок. Ничего «райского» не продаём.
3. **Лимит тапов**: максимум 1 тап в секунду (длинные зикры — дольше, см. `minIntervalMs`).
   Медленнее — можно сколько угодно. Плюс защита от автотапера (`lib/logic/tap_guard.dart`).
4. **В саду нет людей и животных** — только растения, вода, здания, свет.
5. Везде напоминание: «это образ для мотивации, настоящая награда только у Аллаха».
6. **Тексты зикров и хадисов** — только из проверенных источников (Хисн аль-Муслим),
   перед публикацией проверяет устаз. Список к проверке: `docs/content-review.md`.
7. Языки: казахский (по умолчанию) и русский. Английский — позже.
8. Дизайн не менее важен, чем функционал: яркий, сочный, анимированный, в духе
   казуальных игр (Candy Crush, Hay Day, Gardenscapes) — **но свои рисунки, ничего не копировать**.
9. Это приложение, не сайт. Web-сборка используется только для демо.

## Структура
```
lib/
  main.dart                 — вход, глобальный `game` (GameState)
  data/dhikrs.dart          — список зикров (арабский, транслит, kz/ru, достоинство, цель, лимит, капли)
  data/gardens.dart         — сады: тема (цвета неба/холмов) и предметы с ценой и позицией
  logic/tap_guard.dart      — лимит скорости + детектор автотапера (есть тесты)
  state/game_state.dart     — прогресс игрока, сохранение (shared_preferences), стрик
  l10n/strings.dart         — строки kz/ru, функция tr()
  screens/home_screen.dart  — главный экран: сад, капли, стрик, кнопка «Вырастить», кнопка «Зикры»
  screens/dhikr_list_screen.dart — список зикров
  screens/tasbih_screen.dart     — экран тапа (счётчик, кольцо прогресса, +капли)
  screens/map_screen.dart        — карта садов (тропинка, замки, прогресс)
  widgets/garden_painter.dart    — сад рисуется кодом (CustomPainter), пока нет графики
  widgets/garden_view.dart       — анимация сада (качание, «выпрыгивание» нового предмета)
  widgets/juicy.dart             — «сочные» кнопки и плашки
test/tap_guard_test.dart
docs/                       — план, дизайн-бриф, список на проверку устазу
```

## Как запускать
```bash
flutter pub get
flutter run                 # на подключённом телефоне/эмуляторе
flutter run -d chrome       # быстрый просмотр в браузере
flutter test && flutter analyze
flutter build web --release --no-web-resources-cdn   # демо для показа
```
Демо-чит: долгое нажатие на серую подпись внизу главного экрана даёт +500 капель
(`GameState.demoBonus`). Убрать перед релизом.

## Техрешения
- Flutter stable 3.47, Dart 3.13. Пакеты: `shared_preferences`, `flutter_animate`.
- Состояние: один `ChangeNotifier` (`GameState`) + `ListenableBuilder`. Riverpod/Bloc не нужны, пока проект маленький.
- Прогресс хранится локально в JSON. Firebase (вход Google/Apple + облако) — этап 2.
- Сад рисуется кодом, чтобы демо работало без художника. Этап дизайна: заменить
  `GardenPainter` на спрайты (PNG/SVG, сгенерированные ИИ или нарисованные) или Rive-анимации.
  Кандидаты: `flame` (игровой движок), `rive`, `lottie`, `flutter_animate` (уже есть).
- Дизайн-референсы и ТЗ для графики: `docs/design-brief.md`.

## План (этапы)
1. **MVP (сейчас):** зикры, тасбих с лимитом, сад 1–3, карта садов, стрик, kz/ru, локальное хранение. ✅ каркас есть
2. Графика: сгенерировать/нарисовать набор предметов сада, фон, иконку; звуки природы; haptics.
   Вход в игру: сплэш (логотип + капля) → онбординг 3 экрана (зикр → капли → сад, выбор языка,
   напоминание про ният) → обучение при первом запуске (стрелка на «Зикры», первые 33 тапа дают траву
   с праздничной анимацией). Потом приложение всегда открывается сразу в сад, без меню «Начать игру».
3. Напоминания (утро/вечер), квесты (Рамадан, 10 дней Зуль-Хиджа, 40 дней истигфара), хадис дня, аудио произношения.
4. Firebase: вход, облачное сохранение, аналитика, Crashlytics. Пользовательские зикры (добавить свой).
5. Публикация: App Store ($99/год, купить перед релизом) + Google Play ($25). Политика конфиденциальности.
6. Позже / под вопросом: тренировки, группы для близких с общей целью, админка.
