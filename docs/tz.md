## 1. Что это

Мобильная игра (iOS + Android, Flutter) для мусульман Казахстана. Пользователь делает зикр
(тапает по экрану, как на тасбихе), за это получает «капли Каусара» 💧 и растит ими свой сад:
трава → цветы → деревья → пальма → ручей → беседка. Когда сад вырос, открывается следующий
(карта садов, как карта уровней). Опора на хадисы о «саженцах рая» (тасбих, тахмид, тахлиль, такбир).

Аудитория: мусульмане Казахстана, языки казахский (по умолчанию) и русский.

## 2. Жёсткие правила продукта (нельзя менять без согласия Qazaq)

1. **Никакого соревнования по зикрам.** Нет рейтингов, лайков, публичного счёта. Причина: рия.
2. **Полностью бесплатно.** Никаких покупок, рекламы, подписок.
3. **Лимит тапов**: максимум 1 тап/сек (длинные зикры дольше, `minIntervalMs` у зикра) плюс
   детектор автотапера (`lib/logic/tap_guard.dart`). Сейчас выключен флагом для демо, см. п. 6.
4. **В саду нет людей и животных** — только растения, вода, постройки, свет.
5. Везде напоминание: «это образ для мотивации, настоящая награда только у Аллаха».
6. **Тексты зикров и хадисов** — только из проверенных источников (Хисн аль-Муслим). Перед
   публикацией проверяет устаз, список: `docs/content-review.md`. Не добавлять зикры «из головы».
7. Языки: kz (по умолчанию) и ru. Английский позже.
8. Дизайн важен не меньше функционала: яркий, сочный, анимированный, в духе казуальных игр,
   но **свои рисунки, ничего не копировать**.
9. Это приложение, не сайт. Web-сборка только для демо.

## 4. Что делать дальше (по приоритету)

### 4.1. Графика через Recraft (идёт сейчас)
- Стиль уже выбран: яркая 2D-иллюстрация (см. первое дерево у Qazaq в Recraft). Стиль сохранён
  в Recraft под именем `Kausar`, генерить только с ним.
- Промпты и имена файлов: `docs/recraft-prompts.md`. Готовый PNG класть в `assets/garden/<имя>.png`
  рядом с одноимённым SVG, код сам возьмёт PNG. После добавления файлов — перезапуск приложения
  (меняется asset manifest).
- У растений внизу пятачок травы, у построек — каменная площадка, чтобы одинаково «стояли».
- Цветы пока SVG (перекрашиваются кодом в 5 цветов). Если делать PNG, нужны варианты по цветам:
  добавить в `Sprites` выбор файла по цвету (`flower_3_pink.png` и т.д.).
- Иконка приложения: капля + росток/пальма. Сгенерить, подключить через `flutter_launcher_icons`.
- **Готово, когда:** все предметы из `Sprites.files` в PNG одного стиля, сад 1–3 выглядит цельно,
  иконка стоит на iOS и Android.

### 4.2. Вход в игру (описано в CLAUDE.md, план этап 2)
1. **Сплэш**: логотип Кәусар + капля, 1–2 с, затем сразу в сад.
2. **Онбординг** (только первый запуск), 3 экрана с картинками: «Делай зикр → получай капли →
   расти свой сад», выбор языка kz/ru, напоминание про ният и что сад — образ для мотивации.
3. **Обучение в игре** (первый запуск): сад пустой, стрелка показывает на кнопку «Зикры».
   После первых 33 тапов сад даёт первую траву с праздничной анимацией.
4. Потом приложение всегда открывается сразу в сад, без меню «Начать игру».
- Флаг «онбординг пройден» хранить в `GameState` (сохраняется в JSON).
- **Готово, когда:** новый пользователь проходит путь до первой травы без подсказок со стороны.

### 4.3. Отклик и звук
- Haptics на каждый засчитанный тап (`HapticFeedback.lightImpact`), отдельный на достижение цели.
- Мягкий «щелчок» тасбиха, звуки природы в саду (вода, птицы нельзя — животные; ветер, листья, ручей),
  включаются/выключаются в настройках. Пакет `audioplayers`.
- Салют/конфетти при завершении сада (без людей и животных).

### 4.4. Этап 3
- Напоминания утро/вечер (`flutter_local_notifications`), настраиваемое время.
- Квесты: Рамадан, 10 дней Зуль-Хиджа, 40 дней истигфара. Квест = цель по зикрам на период,
  награда — особый предмет сада. Без рейтингов.
- Хадис дня (тексты только после проверки устаза).
- Аудио произношения зикров (записать с чтецом или проверенный источник).

### 4.5. Этап 4: Firebase
- Вход Google/Apple, облачное сохранение прогресса (merge с локальным), Analytics, Crashlytics.
- Пользовательские зикры (добавить свой) — хранить локально и в облаке.

### 4.6. Этап 5: публикация
- App Store ($99/год) + Google Play ($25). Политика конфиденциальности (без рекламы, без продажи данных).
- Чек-лист перед релизом в п. 6.

## 5. Технические требования

- Flutter stable 3.47, Dart 3.13. Пакеты: `shared_preferences`, `flutter_animate`, `flutter_svg`.
- Состояние: один `ChangeNotifier` (`GameState`) + `ListenableBuilder`. Без Riverpod/Bloc, пока
  проект маленький. Не переписывать архитектуру без согласия Qazaq.
- Прогресс: локальный JSON в `shared_preferences`, ключ `kausar_state_v1`. При изменении формата —
  миграция, не терять прогресс.
- Локализация: все строки через `tr('key', lang)` в `lib/l10n/strings.dart`, kz и ru одновременно.
- Сад: координаты предметов 0..1 в `gardens.dart`, спрайты по именам в `Sprites.files`.
- Качество: `flutter analyze` без замечаний и `flutter test` зелёный перед каждым коммитом.
  Новая логика — с тестами (`test/`).
- Производительность: 60 fps на среднем Android. Не плодить CustomPainter с `shouldRepaint = true`
  там, где можно обойтись виджетами.

## 7. Как работать

### Запуск
```bash
flutter pub get
flutter run                 # телефон/эмулятор
flutter run -d chrome       # быстрый просмотр
flutter test && flutter analyze
flutter build web --release --no-web-resources-cdn   # демо
```
Для iOS нужен Xcode (App Store) + `sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer`,
`sudo xcodebuild -runFirstLaunch`, `brew install cocoapods`. Для Android — Android Studio
и `flutter doctor --android-licenses`.

### Git
- Оригинал репозитория остаётся у Qazaq: `MakeByShake/Kausar`. Разработчик работает **в своей ветке**
  (`feature/<задача>`) или **в форке** и открывает Pull Request в `main`. В `main` напрямую не пушить.
- PR мерджит Qazaq после проверки. Один PR = одна задача из п. 4.
- Коммиты короткие, на русском или английском. Перед работой `git pull`.

### Claude Code
Проект ведётся с Claude Code: сначала он читает `CLAUDE.md`. Если продолжаешь с ним —
скажи «Прочитай CLAUDE.md и docs/tz.md» и назови задачу из п. 4. Перед большими изменениями
Claude описывает план и ждёт «ок». Все изменения продуктовых правил — только через Qazaq.

### Вопросы
Любые сомнения по тексту зикров, названию, изображениям построек (купол, дворец) — не решать
самостоятельно, записать в `docs/content-review.md` для устаза и сообщить Qazaq.
